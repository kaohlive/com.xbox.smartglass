Microsoft account

Sign in with the Microsoft account linked to your Xbox so the app can show app names and box art in the device's currently-playing tile.

This is optional. Without it, on/off, button input and media controls all still work — only the cosmetic "now playing" info needs it.

Xbox Live profile tracking

Adds background polling of your Xbox Live profile so Homey can react to achievements you unlock, friends coming online, and gamerscore changes. Adds a "Gamerscore" tile to each Xbox device and makes the Achievement unlocked and Friend came online flow triggers available. Polls about once a minute.

Event log

Recent interesting Xbox Live events captured by the background poller — achievements unlocked, friends coming online or going offline, and diagnostics when something looks off. Holds the last 200 entries.
