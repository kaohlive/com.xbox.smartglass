This is optional. Without it, on/off, button input and media controls all still work — only the cosmetic "now playing" info needs it.

Advanced — paste a refresh token manually

Use this only if the normal sign-in flow doesn't work for you (for example, the redirect back to Homey times out). Open the Microsoft consent URL in a private browser window, sign in, and paste the refresh_token value from the redirect URL fragment.

  1. Open the Microsoft sign-in URL in a private/incognito window.
  2. Sign in. The browser will end on a blank page.
  3. Copy the entire URL from the address bar and paste it below — we'll extract the refresh token automatically.
